Sobre CraftPedia

Una enciclopedia fan hecha por jugadores, para jugadores. Simple, rápida y con datos reales guardados en PostgreSQL.

Nuestra idea

Menos pestañas, más juego

CraftPedia nació como un proyecto académico de INF211 con una idea simple: reunir en un solo lugar los ítems y las guías que un jugador necesita, sin anuncios ni laberintos de enlaces.

Cada ficha muestra la categoría, la rareza, la versión y cómo se obtiene el objeto. Cada guía explica los pasos con una dificultad y un tiempo estimado. Todo se lee desde una base de datos PostgreSQL real.

Cómo trabajamos

Principios del proyecto

Tres reglas simples que guían cada ficha, cada guía y cada línea de código.

Datos claros

Cada ítem tiene categoría, rareza, versión, stack y forma de obtención. Sin información inventada ni relleno.

Rápido y accesible

HTML semántico, navegación por teclado, estados de carga y diseño responsive en cualquier pantalla.

Comunidad primero

Cualquier jugador puede agregar ítems y enviar sugerencias. La enciclopedia mejora con cada aporte.

Detrás del proyecto

Un equipo de una persona

CraftPedia fue diseñada y programada como parte de la evaluación práctica de INF211. La idea, el esquema de la base de datos, la API y el frontend fueron construidos desde cero.

CP
Estudiante INF211 Desarrollo full stack · 2026

1. Diseño de la base de datos

Tablas de categorías, ítems, guías y mensajes, con claves foráneas, restricciones e índices.

2. API con Express

Endpoints de lectura, filtros combinados, detalle e inserción con validación en el servidor.

3. Frontend con Bootstrap

Cinco páginas con navegación consistente, catálogo filtrable, guías y formularios conectados a la API.

4. Pruebas y documentación

Pruebas de extremo a extremo, dump portable, capturas y README con instrucciones de instalación.
